# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1+07] - 2026-05-26
- **Android Build:** Migrated to Flutter's 'Built-in Kotlin' Gradle configuration for future compatibility.
- **AI Settings:** Refactored AI configuration to securely store Gemini API keys and HuggingFace tokens using `flutter_secure_storage`.
- **UI/UX Enhancements:** Updated AI setup modal with step-by-step instructions, clickable links, and in-button progress indicators for a more intuitive user experience.

## [0.0.1+06] - 2026-05-16
- **Word Cloud Feature:** Enhanced with theme-aware coloring (primary/secondary/tertiary colors) and fixed navigation syntax.
- **UI/UX Enhancements:** Fixed alignment issues in Journal Entry cards by correcting `crossAxisAlignment` in the `Column` widget.
- **Feature Additions:** Implemented dynamic word cloud visualization with configurable stopwords and time-range filtering.

## [0.0.1+05] - 2026-05-15
- **Project Pivot:** Initial commit to GitHub.
- **Core Functionality:** Established basic services and logging capabilities.
